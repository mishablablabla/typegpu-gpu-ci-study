# WS-ADJ scoreboard - who is the outlier where Lavapipe and SwiftShader disagree (criterion C4, truth proximity)

Generated by `tools/build-scoreboard.mjs` from `lane-adjudication.json`, `tests-inventory.json`, `experiments.json`, `suite-examples-oracle.json`, `typegpu-usage.json` (all in this directory). Machine-readable twin: `scoreboard.json`. Frozen Phase-1/2 data was only read.

## Method (fixed before the totals were computed)
- **Oracle order** per root cause: (1) spec-defined result or WGSL/IEEE rule; (2) the real CTS interval (`third_party/cts-oracle.cjs`, frozen evaluator `judge()`; categories keep the Phase-1 meaning: accepted = inside a bounded interval, rejected = outside, indeterminate = NaN operand or unbounded interval, unverified = no result); (3) Metal result as a **non-authoritative** real-GPU reference; (4) none (UNVERIFIED). "accepted" is never written as "correct", green is not correct and red is not defect.
- **Strict outcome** uses only (1)+(2): `lavapipe-outlier` / `ss-outlier` (the backend is rejected by the oracle or violates a spec rule while the other is not), `both-fine` (both accepted / spec-permitted), `both-off`, `indeterminate` (no authoritative oracle decides), `capability-gap` (one backend cannot run the code at all; no verdict possible).
- **Lean** (informational, level 3): the side that disagrees with the references that agree with each other (f64/IEEE value and Metal; "Metal neither" is neutral) is `*-leaning-off`; if the two references point to different sides it is `mixed/none`. It is never an outlier verdict.
- **Relevance** (0-3, hand-assigned from `typegpu-usage.json`, scan of the pristine snapshot `_shared/typegpu-HEAD`: 97 docs examples + library packages): 3 = behaviour is exercised by many examples/libs and visible in outputs or the suite cannot run; 2 = widely used function, differences are last-bit only; 1 = function used but the diverging behaviour is a domain edge / exotic input; 0 = no known use. Weighted totals sum these scores per outcome.
- **Scope**: lane groups A-D, L (195 210 lanes x Lavapipe, SS-arm64 [LLVM], SS-x64 [Subzero], Metal), 1 433 investigation-suite tests (30 differ on some backend), 426 full-suite tests (55 differ), 13 docs-example tests. Sample-based items are marked.

## Headline
- Lane level: **rejected = 0 on all four backends** (Lavapipe, SS-arm64, SS-x64, Metal) in all 195 210 lanes; every lane where Lavapipe and a SwiftShader variant differ in value has the **same CTS category on both sides** (accepted/accepted or indeterminate/indeterminate). The CTS interval therefore cannot name an outlier at lane level (checked in code: see `checks` in scoreboard.json).
- Sampled suite lanes (asin/acos/mix/mix_s/fract examples, 1172 distinct backend/function/lane combinations): 0 rejected on Lavapipe, SwiftShader and Metal.
